# Workshop exercise

Work through these tickets in order:

1. [Issue #1 — Investigate inconsistent behavior](https://github.com/datarootsio/data-cleaning-workshop/issues/1).
2. [Issue #2 — Make numeric columns easier to investigate](https://github.com/datarootsio/data-cleaning-workshop/issues/2).

Create your own branch before making changes. Diagnose and fix the first ticket before starting the feature.
Ask the facilitator questions when a report or requirement is unclear, and record the answers and assumptions you use.

For each change, capture evidence of the original behavior, explain your diagnosis, and add a regression test or a
behavioral test that demonstrates the outcome. Check that your fix addresses the cause and that nearby behavior still works.

For the feature, agree a small scope with the facilitator before implementing it. Use your judgment on the design.
Bring your diagnosis, changes, test results, and remaining uncertainties to the debrief so we can compare approaches.

See [CONTRIBUTING.md](CONTRIBUTING.md) for setup and validation commands.
