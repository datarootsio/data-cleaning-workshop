## Frequently asked questions

We collect and share FAQs and responses on Github at [https://github.com/datarootsio/data-cleaning-workshop](https://github.com/datarootsio/data-cleaning-workshop). If you don’t find your problem and solution there, continue on to the resources in the Community section to see more conversations and look for solutions.  

## Community

If you’re having a problem:
*   Search the [User forum](https://github.com/datarootsio/data-cleaning-workshop) to see if the problem is already reported
*   Read [Github issues](https://github.com/datarootsio/data-cleaning-workshop) to see if the problem is already reported
*   Read [Stack Overflow](https://github.com/datarootsio/data-cleaning-workshop) to see if the problem is already reported
*   Check [Twitter](https://github.com/datarootsio/data-cleaning-workshop) to see if others are discussing the problem
*   Report an issue: 
    *   First as a new thread in the User forum
    *   Then, if you wish, you can create a Github issue.

If you want to contribute:
*   [Help us translate the tool into more languages](https://github.com/datarootsio/data-cleaning-workshop), using Weblate
*   [We have a guide to contributing](https://github.com/datarootsio/data-cleaning-workshop) in the Technical Reference section
*   Contribute your feature requests in the [User forum](https://github.com/datarootsio/data-cleaning-workshop) or as [Github issues](https://github.com/datarootsio/data-cleaning-workshop)
*   Join the User Forum and/or the [Developer Forum](https://github.com/datarootsio/data-cleaning-workshop)
*   Share your successes and use cases with us, in the User forum
*   Add your [blog posts, guides, tips, tricks, tutorials to our list](https://github.com/datarootsio/data-cleaning-workshop)
*   Keep an eye out for and respond to our biennial user survey.
