OpenRefine's development roadmap presents the broad directions in which the project wants to go in the coming years, based on input from user surveys and interests in the developer community. You can find the roadmap on OpenRefine's wiki: https://github.com/OpenRefine/OpenRefine/wiki/Roadmap

This roadmap is incomplete, is always work in progress, and is a collaborative effort of the Data Cleaning Workshop community (users, developers and other stakeholders).

See also: 
* [Milestones (Data Cleaning Workshop core repository)](https://github.com/datarootsio/data-cleaning-workshop)
* [Projects (Data Cleaning Workshop core repository)](https://github.com/datarootsio/data-cleaning-workshop)
* [Projects (across repositories)](https://github.com/datarootsio/data-cleaning-workshop)
* [issues (Data Cleaning Workshop core repository)](https://github.com/datarootsio/data-cleaning-workshop) in Github

If there are features you would like to see that are not currently listed here or in the above-mentioned places, please add them to our [issue tracker](https://github.com/datarootsio/data-cleaning-workshop).
