# Workshop governance

The dataroots workshop facilitators maintain this repository and its exercise scope. Participants contribute through their
own branches and, when requested, pull requests. Facilitators review changes for behavior, evidence, tests, and suitability
for future sessions. Workshop questions and proposals belong in this repository's issues or the session discussion.

Participants are encouraged to explain alternatives and challenge assumptions respectfully. Facilitators make the final
scope and repository maintenance decisions. Everyone follows the [Code of Conduct](CODE_OF_CONDUCT.md).

This training repository has its own maintenance process and does not represent the governance or decisions of the project
from which the application was derived.
